# Colorado Aspen & Trails

Interactive map of Colorado hiking trails (CPW COTREX) over aspen density.

**Live map:** https://theweathermanda.github.io/aspen-trail-map/

Layers (all streamed live):
- **Aspen basal area** – USFS Individual Tree Species Parameter maps, quaking aspen, 30 m, ft²/acre (~2002 vintage)
- **Aspen stands** – LANDFIRE 2024 Existing Vegetation Type, classes 7011 (Rocky Mountain Aspen) and 7061 (Aspen–Mixed Conifer)
- **Trails** – Colorado Parks & Wildlife COTREX, hiking-allowed by default (zoom 11+)

Tap the map to read aspen values at a point.
